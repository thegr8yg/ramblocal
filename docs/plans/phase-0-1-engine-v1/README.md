# Phase 0-1: Hardware Gate + Engine v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the GTX 1080 and toolchain can run the plan, then produce a correct Parakeet TDT transcription engine in Go (ONNX Runtime backend) plus the benchmark harness every later phase depends on.

**Architecture:** NeMo exports Parakeet to three ONNX graphs (preprocessor, encoder, decoder+joint) and a `manifest.json` describing them. Go code loads them with `onnxruntime_go`, runs the TDT greedy decoding loop in Go, and detokenizes. Golden fixtures generated by NeMo are the test oracle. `rbbench` measures WER, RTF, latency percentiles and VRAM, and scores hypotheses produced by external scripts (NeMo reference, faster-whisper baseline) with the same Go normalizer.

**Tech Stack:** Go ≥ 1.24, `github.com/yalue/onnxruntime_go`, ONNX Runtime (GPU build), CUDA 12.x + MSVC (probes only), Python 3.11 + NeMo on a Lambda Linux instance (export only), PowerShell scripts.

**Spec:** [../../spec/README.md](../../spec/README.md) · **Roadmap:** [../../roadmap/README.md](../../roadmap/README.md)

## Global Constraints

- Go module path: `github.com/thegr8yg/ramblocal`. `go.mod` declares `go 1.24`.
- Audio inside the engine is 16 kHz mono `float32` in [-1, 1].
- Default model: `nvidia/parakeet-tdt-0.6b-v2`. Model files live in `models/<name>/` and are never committed (`models/` is in `.gitignore`).
- `manifest.json` is the only source of tensor names, dtypes, blank id and TDT durations. No Go code hard-codes them.
- Execution provider order: `cuda`, `dml`, `cpu`. The active EP is always reported.
- Greedy decoding cap: `maxSymbolsPerFrame = 10` (must equal the NeMo golden config).
- Integration tests that need the GPU, ORT, or models skip unless `RAMBLOCAL_ORT_LIB` and `RAMBLOCAL_MODEL_DIR` are set. `go test ./...` must pass on a machine with neither.
- No transcript text is ever executed.
- Anything writing to `bench/results/` acquires the GPU lock (Task 1.8).
- Commit messages: conventional commits (`feat:`, `test:`, `chore:`, `docs:`), ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` when written by an agent.

## Review Focus

1. **Silent or empty audio** (0 samples, or 2 s of zeros): `Transcribe` returns an empty or short text with no error and no panic. → Task 1.6, `TestTranscribeEdgeAudio`.
2. **Audio shorter than one encoder frame** (50 ms): returns empty text, no ORT shape error. → Task 1.6, `TestTranscribeEdgeAudio`.
3. **Long audio** (40 s, longer than any training clip the user will feed in Phase 1): transcribes without error. → Task 1.6, `TestTranscribeEdgeAudio`.
4. **Real-world WAV headers** (stereo, `WAVE_FORMAT_EXTENSIBLE`, 24-bit, odd-sized `LIST` chunk before `data`): decode correctly or fail with a clear error, never misread samples. → Task 1.2.
5. **Pathological joint output** (always non-blank with duration 0): decoder terminates via the symbols-per-frame cap instead of looping forever. → Task 1.4, `TestGreedyTDTSymbolCap`.

```cuda
// Verifies: nvcc can target sm_61, kernels run, and the INT8 dp4a instruction works.
#include <cstdio>
#include <cuda_runtime.h>

__global__ void vecadd(const float* a, const float* b, float* c, int n) {
    int i = blockIdx.x * blockDim.x + threadIdx.x;
    if (i < n) c[i] = a[i] + b[i];
}

__global__ void dp4a_kernel(const int* a, const int* b, int* out) {
    out[0] = __dp4a(a[0], b[0], 0);
}

int main() {
    const int n = 1 << 20;
    float *a, *b, *c;
    cudaMallocManaged(&a, n * sizeof(float));
    cudaMallocManaged(&b, n * sizeof(float));
    cudaMallocManaged(&c, n * sizeof(float));
    for (int i = 0; i < n; i++) { a[i] = 1.0f; b[i] = 2.0f; }
    vecadd<<<(n + 255) / 256, 256>>>(a, b, c, n);
    cudaError_t err = cudaDeviceSynchronize();
    if (err != cudaSuccess) { printf("{\"error\":\"%s\"}\n", cudaGetErrorString(err)); return 1; }
    for (int i = 0; i < n; i++) if (c[i] != 3.0f) { printf("{\"error\":\"vecadd mismatch at %d\"}\n", i); return 1; }

    // Pack bytes (1,2,3,4) and (5,6,7,8) as signed int8x4. Expected dot = 1*5+2*6+3*7+4*8 = 70.
    int *da, *db, *dout;
    cudaMallocManaged(&da, sizeof(int));
    cudaMallocManaged(&db, sizeof(int));
    cudaMallocManaged(&dout, sizeof(int));
    *da = 0x04030201; *db = 0x08070605;
    dp4a_kernel<<<1, 1>>>(da, db, dout);
    err = cudaDeviceSynchronize();
    int dp4a_ok = (err == cudaSuccess && *dout == 70);

    cudaDeviceProp p;
    cudaGetDeviceProperties(&p, 0);
    printf("{\"gpu\":\"%s\",\"sm\":\"%d%d\",\"dp4a_ok\":%s}\n", p.name, p.major, p.minor, dp4a_ok ? "true" : "false");
    return dp4a_ok ? 0 : 1;
}
```

`probes/dll/probe.cu`:
```cuda
#include <cuda_runtime.h>

__global__ void add_kernel(int a, int b, int* out) { *out = a + b; }

// Returns a+b computed on the GPU, or -1 on any CUDA error.
extern "C" __declspec(dllexport) int rb_probe_gpu_add(int a, int b) {
    int* d = nullptr;
    if (cudaMallocManaged(&d, sizeof(int)) != cudaSuccess) return -1;
    add_kernel<<<1, 1>>>(a, b, d);
    if (cudaDeviceSynchronize() != cudaSuccess) { cudaFree(d); return -1; }
    int r = *d;
    cudaFree(d);
    return r;
}
```

`tools/export/export_parakeet.py`:
```python
"""Export Parakeet TDT to ONNX + manifest.json + golden fixtures.

Usage:
  python export_parakeet.py --model nvidia/parakeet-tdt-0.6b-v2 \
      --out models/parakeet-tdt-0.6b-v2 --golden-out testdata/golden \
      --golden-wavs clips/*.wav
"""
import argparse
import json
import pathlib

import numpy as np
import onnx
import soundfile as sf
import torch
from omegaconf import open_dict

import nemo.collections.asr as nemo_asr

DECODER_INPUT_ORDER = ["encoder_outputs", "targets", "target_length", "input_states_1", "input_states_2"]
DECODER_OUTPUT_ORDER = ["outputs", "prednet_lengths", "output_states_1", "output_states_2"]


def graph_io(path):
    g = onnx.load(str(path), load_external_data=False).graph
    dtypes = {}
    for v in list(g.input) + list(g.output):
        dtypes[v.name] = onnx.TensorProto.DataType.Name(v.type.tensor_type.elem_type).lower()
    return [i.name for i in g.input], [o.name for o in g.output], dtypes


def ordered(names, wanted, what):
    """Return names reordered to match `wanted`; fail loudly if the export changed names."""
    missing = [w for w in wanted if w not in names]
    if missing:
        raise SystemExit(f"{what}: expected tensor names {wanted}, export has {names}")
    return list(wanted)


def resave(src, dst):
    """Re-save with all weights in one external-data file (encoder exceeds the 2 GB protobuf limit)."""
    m = onnx.load(str(src), load_external_data=True)
    onnx.save_model(m, str(dst), save_as_external_data=True,
                    all_tensors_to_one_file=True, location=dst.name + ".data")


class Pre(torch.nn.Module):
    def __init__(self, p):
        super().__init__()
        self.p = p

    def forward(self, waveforms, waveforms_lens):
        return self.p(input_signal=waveforms, length=waveforms_lens)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--model", default="nvidia/parakeet-tdt-0.6b-v2")
    ap.add_argument("--out", required=True)
    ap.add_argument("--golden-out", required=True)
    ap.add_argument("--golden-wavs", nargs="+", required=True)
    args = ap.parse_args()

    out = pathlib.Path(args.out)
    out.mkdir(parents=True, exist_ok=True)
    tmp = out / "_export"
    tmp.mkdir(exist_ok=True)

    m = nemo_asr.models.ASRModel.from_pretrained(args.model, map_location="cpu").eval()
    m.preprocessor.featurizer.dither = 0.0
    m.preprocessor.featurizer.pad_to = 0

    dc = m.cfg.decoding
    with open_dict(dc):
        dc.strategy = "greedy"
        dc.greedy.max_symbols = 10
    m.change_decoding_strategy(dc)

    # Encoder + decoder_joint via NeMo's exporter.
    m.export(str(tmp / "model.onnx"))
    resave(next(tmp.glob("encoder*.onnx")), out / "encoder.onnx")
    resave(next(tmp.glob("decoder_joint*.onnx")), out / "decoder_joint.onnx")

    # Preprocessor via torch.onnx (opset 17 has STFT). If this raises, see tools/export/README.md fallback.
    torch.onnx.export(
        Pre(m.preprocessor), (torch.zeros(1, 16000), torch.tensor([16000])),
        str(out / "preprocessor.onnx"),
        input_names=["waveforms", "waveforms_lens"], output_names=["features", "features_lens"],
        dynamic_axes={"waveforms": {1: "n"}, "features": {2: "t"}}, opset_version=17, dynamo=False,
    )

    vocab_size = m.tokenizer.vocab_size
    with open(out / "vocab.txt", "w", encoding="utf-8") as f:
        for i in range(vocab_size):
            f.write(m.tokenizer.ids_to_tokens([i])[0] + "\n")

    pre_in, pre_out, pre_dt = graph_io(out / "preprocessor.onnx")
    enc_in, enc_out, enc_dt = graph_io(out / "encoder.onnx")
    dj_in, dj_out, dj_dt = graph_io(out / "decoder_joint.onnx")
    manifest = {
        "name": args.model.split("/")[-1],
        "sample_rate": int(m.cfg.preprocessor.sample_rate),
        "num_features": int(m.cfg.preprocessor.features),
        "hop_seconds": float(m.cfg.preprocessor.window_stride),
        "subsampling": int(m.cfg.encoder.subsampling_factor),
        "encoder_dim": int(m.cfg.encoder.d_model),
        "vocab_size": int(vocab_size),
        "blank_id": int(vocab_size),
        "tdt_durations": [int(d) for d in m.cfg.model_defaults.tdt_durations],
        "pred_layers": int(m.cfg.decoder.prednet.pred_rnn_layers),
        "pred_hidden": int(m.cfg.decoder.prednet.pred_hidden),
        "preprocessor": {"file": "preprocessor.onnx", "inputs": pre_in, "outputs": pre_out, "dtypes": pre_dt},
        "encoder": {"file": "encoder.onnx", "inputs": enc_in, "outputs": enc_out, "dtypes": enc_dt},
        "decoder_joint": {
            "file": "decoder_joint.onnx",
            "inputs": ordered(dj_in, DECODER_INPUT_ORDER, "decoder_joint inputs"),
            "outputs": ordered(dj_out, DECODER_OUTPUT_ORDER, "decoder_joint outputs"),
            "dtypes": dj_dt,
        },
    }
    (out / "manifest.json").write_text(json.dumps(manifest, indent=2))

    gold = pathlib.Path(args.golden_out)
    gold.mkdir(parents=True, exist_ok=True)
    for wav in args.golden_wavs:
        wav = pathlib.Path(wav)
        audio, sr = sf.read(wav, dtype="float32")
        assert sr == 16000 and audio.ndim == 1, f"{wav}: need 16 kHz mono"
        x = torch.from_numpy(audio)[None]
        xl = torch.tensor([x.shape[1]])
        with torch.no_grad():
            feats, fl = m.preprocessor(input_signal=x, length=xl)
            enc, el = m.encoder(audio_signal=feats, length=fl)
        hyp = m.transcribe([str(wav)], return_hypotheses=True)[0]
        if isinstance(hyp, list):
            hyp = hyp[0]
        mel = feats[0, :, : int(fl[0])].numpy().astype("<f4")
        e = enc[0, :, : int(el[0])].numpy().astype("<f4")
        name = wav.stem
        sf.write(gold / f"{name}.wav", audio, 16000, subtype="PCM_16")
        np.ascontiguousarray(mel).tofile(gold / f"{name}.mel.f32")
        np.ascontiguousarray(e).tofile(gold / f"{name}.enc.f32")
        (gold / f"{name}.json").write_text(json.dumps({
            "tokens": [int(t) for t in hyp.y_sequence],
            "text": hyp.text,
            "mel_shape": list(mel.shape),
            "enc_shape": list(e.shape),
        }, indent=2))
        print(f"{name}: {hyp.text}")


if __name__ == "__main__":
    main()
```

```go
// with random features and reports whether it runs and how fast.
package main

import (
	"encoding/json"
	"flag"
	"fmt"
	"math/rand"
	"os"
	"path/filepath"
	"time"

	ort "github.com/yalue/onnxruntime_go"
)

type graph struct {
	File    string            `json:"file"`
	Inputs  []string          `json:"inputs"`
	Outputs []string          `json:"outputs"`
	DTypes  map[string]string `json:"dtypes"`
}

type manifest struct {
	NumFeatures int   `json:"num_features"`
	Encoder     graph `json:"encoder"`
}

type result struct {
	EP       string  `json:"ep"`
	OK       bool    `json:"ok"`
	Error    string  `json:"error,omitempty"`
	FirstMS  float64 `json:"first_ms"`
	SteadyMS float64 `json:"steady_ms"`
}

func main() {
	lib := flag.String("ort", os.Getenv("RAMBLOCAL_ORT_LIB"), "path to onnxruntime.dll")
	dir := flag.String("model", os.Getenv("RAMBLOCAL_MODEL_DIR"), "model directory")
	ep := flag.String("ep", "cuda", "execution provider: cuda, dml, or cpu")
	flag.Parse()

	raw, err := os.ReadFile(filepath.Join(*dir, "manifest.json"))
	must(err)
	var m manifest
	must(json.Unmarshal(raw, &m))

	ort.SetSharedLibraryPath(*lib)
	must(ort.InitializeEnvironment())
	defer ort.DestroyEnvironment()

	res := probe(*dir, m, *ep)
	out, _ := json.MarshalIndent(res, "", "  ")
	fmt.Println(string(out))
	if !res.OK {
		os.Exit(1)
	}
}

func probe(dir string, m manifest, ep string) result {
	r := result{EP: ep}
	opts, err := ort.NewSessionOptions()
	if err != nil {
		r.Error = err.Error()
		return r
	}
	defer opts.Destroy()
	switch ep {
	case "cuda":
		c, err := ort.NewCUDAProviderOptions()
		if err == nil {
			defer c.Destroy()
			err = opts.AppendExecutionProviderCUDA(c)
		}
		if err != nil {
			r.Error = err.Error()
			return r
		}
	case "dml":
		if err := opts.AppendExecutionProviderDirectML(0); err != nil {
			r.Error = err.Error()
			return r
		}
	}
	s, err := ort.NewDynamicAdvancedSession(filepath.Join(dir, m.Encoder.File), m.Encoder.Inputs, m.Encoder.Outputs, opts)
	if err != nil {
		r.Error = err.Error()
		return r
	}
	defer s.Destroy()

	const frames = 1000 // 10 s of audio
	feats := make([]float32, m.NumFeatures*frames)
	for i := range feats {
		feats[i] = rand.Float32()*2 - 1
	}
	in, err := ort.NewTensor(ort.NewShape(1, int64(m.NumFeatures), frames), feats)
	if err != nil {
		r.Error = err.Error()
		return r
	}
	defer in.Destroy()
	var length ort.Value
	if m.Encoder.DTypes[m.Encoder.Inputs[1]] == "int32" {
		length, err = ort.NewTensor(ort.NewShape(1), []int32{frames})
	} else {
		length, err = ort.NewTensor(ort.NewShape(1), []int64{frames})
	}
	if err != nil {
		r.Error = err.Error()
		return r
	}
	defer length.Destroy()

	run := func() (time.Duration, error) {
		outs := make([]ort.Value, len(m.Encoder.Outputs))
		start := time.Now()
		err := s.Run([]ort.Value{in, length}, outs)
		d := time.Since(start)
		for _, o := range outs {
			if o != nil {
				o.Destroy()
			}
		}
		return d, err
	}
	first, err := run()
	if err != nil {
		r.Error = err.Error()
		return r
	}
	var total time.Duration
	for i := 0; i < 10; i++ {
		d, err := run()
		if err != nil {
			r.Error = err.Error()
			return r
		}
		total += d
	}
	r.OK = true
	r.FirstMS = float64(first.Microseconds()) / 1000
	r.SteadyMS = float64(total.Microseconds()) / 10000
	return r
}

func must(err error) {
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(2)
	}
}
```

```go
		return nil, err
```

```go
// Package audio handles PCM audio I/O.
package audio

import (
	"bytes"
	"encoding/binary"
	"errors"
	"fmt"
	"io"
	"math"
)

var (
	ErrNotWAV            = errors.New("not a RIFF/WAVE file")
	ErrUnsupportedFormat = errors.New("unsupported WAV sample format")
)

const (
	fmtPCM        = 1
	fmtFloat      = 3
	fmtExtensible = 0xFFFE
)

// ReadWAV decodes PCM 16/24/32-bit integer or 32-bit float WAV, including WAVE_FORMAT_EXTENSIBLE.
// Channels are averaged to mono. The caller checks the sample rate.
func ReadWAV(r io.Reader) ([]float32, int, error) {
	data, err := io.ReadAll(r)
	if err != nil {
		return nil, 0, err
	}
	if len(data) < 12 || string(data[0:4]) != "RIFF" || string(data[8:12]) != "WAVE" {
		return nil, 0, ErrNotWAV
	}
	le := binary.LittleEndian
	var format, channels, bits uint16
	var rate uint32
	var pcm []byte
	haveFmt, haveData := false, false
	for off := 12; off+8 <= len(data); {
		id := string(data[off : off+4])
		size := int(le.Uint32(data[off+4 : off+8]))
		body := off + 8
		if size > len(data)-body {
			size = len(data) - body // tolerate a truncated final chunk
		}
		switch id {
		case "fmt ":
			if size < 16 {
				return nil, 0, fmt.Errorf("%w: fmt chunk too small", ErrNotWAV)
			}
			format = le.Uint16(data[body:])
			channels = le.Uint16(data[body+2:])
			rate = le.Uint32(data[body+4:])
			bits = le.Uint16(data[body+14:])
			if format == fmtExtensible {
				if size < 26 {
					return nil, 0, fmt.Errorf("%w: extensible fmt chunk too small", ErrNotWAV)
				}
				format = le.Uint16(data[body+24:]) // first two bytes of SubFormat GUID
			}
			haveFmt = true
		case "data":
			pcm = data[body : body+size]
			haveData = true
		}
		off = body + size + size%2
	}
	if !haveFmt || !haveData {
		return nil, 0, fmt.Errorf("%w: missing fmt or data chunk", ErrNotWAV)
	}
	if channels == 0 {
		return nil, 0, fmt.Errorf("%w: zero channels", ErrUnsupportedFormat)
	}

	var sample func(b []byte) float32
	switch {
	case format == fmtPCM && bits == 16:
		sample = func(b []byte) float32 { return float32(int16(le.Uint16(b))) / 32768 }
	case format == fmtPCM && bits == 24:
		sample = func(b []byte) float32 {
			v := int32(b[0]) | int32(b[1])<<8 | int32(int8(b[2]))<<16
			return float32(v) / 8388608
		}
	case format == fmtPCM && bits == 32:
		sample = func(b []byte) float32 { return float32(int32(le.Uint32(b))) / 2147483648 }
	case format == fmtFloat && bits == 32:
		sample = func(b []byte) float32 { return math.Float32frombits(le.Uint32(b)) }
	default:
		return nil, 0, fmt.Errorf("%w: format %d, %d bits", ErrUnsupportedFormat, format, bits)
	}

	bps := int(bits) / 8
	frame := bps * int(channels)
	n := len(pcm) / frame
	out := make([]float32, n)
	for i := 0; i < n; i++ {
		var sum float32
		for c := 0; c < int(channels); c++ {
			o := i*frame + c*bps
			sum += sample(pcm[o : o+bps])
		}
		out[i] = sum / float32(channels)
	}
	return out, int(rate), nil
}

// WriteWAV16 writes mono 16-bit PCM, clamping samples to [-1, 1].
func WriteWAV16(w io.Writer, pcm []float32, sampleRate int) error {
	var b bytes.Buffer
	le := binary.LittleEndian
	dataLen := uint32(len(pcm) * 2)
	b.WriteString("RIFF")
	binary.Write(&b, le, 36+dataLen)
	b.WriteString("WAVEfmt ")
	binary.Write(&b, le, uint32(16))
	binary.Write(&b, le, uint16(fmtPCM))
	binary.Write(&b, le, uint16(1))
	binary.Write(&b, le, uint32(sampleRate))
	binary.Write(&b, le, uint32(sampleRate*2))
	binary.Write(&b, le, uint16(2))
	binary.Write(&b, le, uint16(16))
	b.WriteString("data")
	binary.Write(&b, le, dataLen)
	for _, s := range pcm {
		s = max(-1, min(1, s))
		binary.Write(&b, le, int16(math.Round(float64(s)*32767)))
	}
	_, err := w.Write(b.Bytes())
	return err
}
```

```go
package asr

import (
	"bufio"
	"errors"
	"fmt"
	"io"
	"strings"
)

const wordStart = "▁" // U+2581, SentencePiece word-boundary marker

// Tokenizer maps SentencePiece token ids to text.
type Tokenizer struct {
	pieces []string
}

// LoadVocab reads one piece per line; the line index is the token id.
func LoadVocab(r io.Reader) (*Tokenizer, error) {
	var pieces []string
	sc := bufio.NewScanner(r)
	for sc.Scan() {
		pieces = append(pieces, strings.TrimRight(sc.Text(), "\r"))
	}
	if err := sc.Err(); err != nil {
		return nil, err
	}
	if len(pieces) == 0 {
		return nil, errors.New("vocab is empty")
	}
	return &Tokenizer{pieces: pieces}, nil
}

func (t *Tokenizer) Size() int { return len(t.pieces) }

func (t *Tokenizer) piece(id int) (string, error) {
	if id < 0 || id >= len(t.pieces) {
		return "", fmt.Errorf("token id %d out of range [0,%d)", id, len(t.pieces))
	}
	return t.pieces[id], nil
}

func (t *Tokenizer) Decode(ids []int) (string, error) {
	var b strings.Builder
	for _, id := range ids {
		p, err := t.piece(id)
		if err != nil {
			return "", err
		}
		b.WriteString(p)
	}
	return strings.TrimSpace(strings.ReplaceAll(b.String(), wordStart, " ")), nil
}

// Words groups tokens into words. frames[i] is the encoder frame where ids[i] was emitted.
func (t *Tokenizer) Words(ids, frames []int, frameSec float64) ([]Word, error) {
	if len(ids) != len(frames) {
		return nil, fmt.Errorf("ids (%d) and frames (%d) differ in length", len(ids), len(frames))
	}
	var words []Word
	for i, id := range ids {
		p, err := t.piece(id)
		if err != nil {
			return nil, err
		}
		start := float64(frames[i]) * frameSec
		end := float64(frames[i]+1) * frameSec
		if strings.HasPrefix(p, wordStart) || len(words) == 0 {
			words = append(words, Word{Text: strings.TrimPrefix(p, wordStart), Start: start, End: end})
			continue
		}
		w := &words[len(words)-1]
		if w.Text == "" {
			w.Start = start // a bare "▁" piece opened this word; it starts with this token
		}
		w.Text += p
		w.End = end
	}
	out := words[:0]
	for _, w := range words {
		if w.Text != "" {
			out = append(out, w)
		}
	}
	return out, nil
}
```

```go
type DecoderState any
type Joint interface {
	InitialState() DecoderState
	// Step runs the prediction net on lastToken (from state) and the joint with encoder frame t.
	// tokenLogits has blankID+1 entries (blank last); durLogits has len(durations) entries.
	// next is the prediction-net state after consuming lastToken.

```

Algorithm (Token-and-Duration Transducer greedy search, matching NeMo's greedy TDT):
1. `t = 0`, `last = blank`, `state = InitialState()`, `emitted = 0`.
2. While `t < numFrames`: `Step(t, last, state)`; `k = argmax(tokenLogits)`, `d = durations[argmax(durLogits)]`.
3. If `k != blank`: append `k` at frame `t`; `state = next`; `last = k`; `emitted++`.
4. If `k == blank` and `d == 0`: `d = 1` (blank must advance).
5. If `d == 0` and `emitted >= maxSymbolsPerFrame`: `d = 1`.
6. If `d > 0`: `t += d`; `emitted = 0`.

```go
package asr

import (
	"context"
	"fmt"
)

// DecoderState is the prediction-network state, opaque to the decoding loop.
type DecoderState any

// Joint runs one prediction-network + joint step for a TDT model.
type Joint interface {
	InitialState() DecoderState
	Step(t, lastToken int, state DecoderState) (tokenLogits, durLogits []float32, next DecoderState, err error)
}

// Hyp is a decoded hypothesis: Frames[i] is the encoder frame at which Tokens[i] was emitted.
type Hyp struct {
	Tokens []int
	Frames []int
}

// GreedyTDT runs greedy Token-and-Duration Transducer decoding over numFrames encoder frames.
func GreedyTDT(ctx context.Context, j Joint, numFrames, blankID int, durations []int, maxSymbolsPerFrame int) (Hyp, error) {
	var h Hyp
	state := j.InitialState()
	last := blankID
	emitted := 0
	for t := 0; t < numFrames; {
		if err := ctx.Err(); err != nil {
			return Hyp{}, err
		}
		tok, dur, next, err := j.Step(t, last, state)
		if err != nil {
			return Hyp{}, fmt.Errorf("joint step at frame %d: %w", t, err)
		}
		if len(tok) != blankID+1 || len(dur) != len(durations) {
			return Hyp{}, fmt.Errorf("joint returned %d token / %d duration logits, want %d / %d",
				len(tok), len(dur), blankID+1, len(durations))
		}
		k := argmax(tok)
		d := durations[argmax(dur)]
		if k != blankID {
			h.Tokens = append(h.Tokens, k)
			h.Frames = append(h.Frames, t)
			state = next
			last = k
			emitted++
		} else if d == 0 {
			d = 1
		}
		if d == 0 && emitted >= maxSymbolsPerFrame {
			d = 1
		}
		if d > 0 {
			t += d
			emitted = 0
		}
	}
	return h, nil
}

func argmax(v []float32) int {
	best := 0
	for i := 1; i < len(v); i++ {
		if v[i] > v[best] {
			best = i
		}
	}
	return best
}
```

```go
// Package golden loads NeMo-generated reference fixtures written by tools/export.
package golden

import (
	"encoding/binary"
	"encoding/json"
	"fmt"
	"math"
	"os"
	"path/filepath"
	"sort"
	"strings"

	"github.com/thegr8yg/ramblocal/internal/audio"
)

type Fixture struct {
	Name     string
	PCM      []float32
	Mel      []float32 // [MelShape[0], MelShape[1]] = [features, frames]
	MelShape []int
	Enc      []float32 // [EncShape[0], EncShape[1]] = [dim, frames]
	EncShape []int
	Tokens   []int
	Text     string
}

func List(dir string) ([]string, error) {
	matches, err := filepath.Glob(filepath.Join(dir, "*.json"))
	if err != nil {
		return nil, err
	}
	var names []string
	for _, m := range matches {
		names = append(names, strings.TrimSuffix(filepath.Base(m), ".json"))
	}
	sort.Strings(names)
	return names, nil
}

func Load(dir, name string) (*Fixture, error) {
	base := filepath.Join(dir, name)
	raw, err := os.ReadFile(base + ".json")
	if err != nil {
		return nil, err
	}
	var meta struct {
		Tokens   []int  `json:"tokens"`
		Text     string `json:"text"`
		MelShape []int  `json:"mel_shape"`
		EncShape []int  `json:"enc_shape"`
	}
	if err := json.Unmarshal(raw, &meta); err != nil {
		return nil, fmt.Errorf("%s.json: %w", base, err)
	}
	f, err := os.Open(base + ".wav")
	if err != nil {
		return nil, err
	}
	defer f.Close()
	pcm, rate, err := audio.ReadWAV(f)
	if err != nil {
		return nil, fmt.Errorf("%s.wav: %w", base, err)
	}
	if rate != 16000 {
		return nil, fmt.Errorf("%s.wav: rate %d, want 16000", base, rate)
	}
	mel, err := readF32(base+".mel.f32", product(meta.MelShape))
	if err != nil {
		return nil, err
	}
	enc, err := readF32(base+".enc.f32", product(meta.EncShape))
	if err != nil {
		return nil, err
	}
	return &Fixture{Name: name, PCM: pcm, Mel: mel, MelShape: meta.MelShape, Enc: enc,
		EncShape: meta.EncShape, Tokens: meta.Tokens, Text: meta.Text}, nil
}

func readF32(path string, n int) ([]float32, error) {
	raw, err := os.ReadFile(path)
	if err != nil {
		return nil, err
	}
	if len(raw) != n*4 {
		return nil, fmt.Errorf("%s: %d bytes, want %d", path, len(raw), n*4)
	}
	out := make([]float32, n)
	for i := range out {
		out[i] = math.Float32frombits(binary.LittleEndian.Uint32(raw[i*4:]))
	}
	return out, nil
}

func product(shape []int) int {
	p := 1
	for _, s := range shape {
		p *= s
	}
	return p
}

// MaxAbsDiff returns the largest |a[i]-b[i]| over the shorter length.
func MaxAbsDiff(a, b []float32) float32 {
	var m float32
	for i := 0; i < min(len(a), len(b)); i++ {
		d := a[i] - b[i]
		if d < 0 {
			d = -d
		}
		m = max(m, d)
	}
	return m
}
```

```go
	initOnce sync.Once
	initErr  error
)

// InitRuntime loads onnxruntime.dll once per process.
func InitRuntime(libPath string) error {
	initOnce.Do(func() {
		ort.SetSharedLibraryPath(libPath)
		initErr = ort.InitializeEnvironment()
	})
	return initErr
}

func sessionOptions(ep string) (*ort.SessionOptions, error) {
	opts, err := ort.NewSessionOptions()
	if err != nil {
		return nil, err
	}
	switch ep {
	case "cuda":
		c, err := ort.NewCUDAProviderOptions()
		if err != nil {
			opts.Destroy()
			return nil, err
		}
		defer c.Destroy()
		if err := opts.AppendExecutionProviderCUDA(c); err != nil {
			opts.Destroy()
			return nil, err
		}
	case "dml":
		if err := opts.AppendExecutionProviderDirectML(0); err != nil {
			opts.Destroy()
			return nil, err
		}
	case "cpu":
	default:
		opts.Destroy()
		return nil, fmt.Errorf("unknown execution provider %q", ep)
	}
	return opts, nil
}
```

```go
package ortengine

import (
	"fmt"
	"path/filepath"

	ort "github.com/yalue/onnxruntime_go"

	"github.com/thegr8yg/ramblocal/internal/asr"
)

type graph struct {
	s    *ort.DynamicAdvancedSession
	spec asr.Graph
}

func openGraph(dir string, spec asr.Graph, ep string) (*graph, error) {
	opts, err := sessionOptions(ep)
	if err != nil {
		return nil, err
	}
	defer opts.Destroy()
	s, err := ort.NewDynamicAdvancedSession(filepath.Join(dir, spec.File), spec.Inputs, spec.Outputs, opts)
	if err != nil {
		return nil, fmt.Errorf("open %s on %s: %w", spec.File, ep, err)
	}
	return &graph{s: s, spec: spec}, nil
}

// run executes the graph; the caller must destroyAll the returned outputs.
func (g *graph) run(inputs []ort.Value) ([]ort.Value, error) {
	outs := make([]ort.Value, len(g.spec.Outputs))
	if err := g.s.Run(inputs, outs); err != nil {
		destroyAll(outs)
		return nil, fmt.Errorf("run %s: %w", g.spec.File, err)
	}
	return outs, nil
}

func (g *graph) inDType(i int) string { return g.spec.DTypes[g.spec.Inputs[i]] }

func destroyAll(vs []ort.Value) {
	for _, v := range vs {
		if v != nil {
			v.Destroy()
		}
	}
}

func intTensor(dtype string, shape ort.Shape, vals ...int64) (ort.Value, error) {
	switch dtype {
	case "int64":
		t, err := ort.NewTensor(shape, vals)
		if err != nil {
			return nil, err
		}
		return t, nil
	case "int32":
		v := make([]int32, len(vals))
		for i, x := range vals {
			v[i] = int32(x)
		}
		t, err := ort.NewTensor(shape, v)
		if err != nil {
			return nil, err
		}
		return t, nil
	}
	return nil, fmt.Errorf("unsupported integer dtype %q", dtype)
}

func floatTensor(shape ort.Shape, data []float32) (ort.Value, error) {
	t, err := ort.NewTensor(shape, data)
	if err != nil {
		return nil, err
	}
	return t, nil
}

// floats copies a float32 output so it survives Destroy.
func floats(v ort.Value) ([]float32, ort.Shape, error) {
	t, ok := v.(*ort.Tensor[float32])
	if !ok {
		return nil, nil, fmt.Errorf("expected float32 tensor, got %T", v)
	}
	return append([]float32(nil), t.GetData()...), t.GetShape(), nil
}

func firstInt(v ort.Value) (int, error) {
	switch t := v.(type) {
	case *ort.Tensor[int64]:
		return int(t.GetData()[0]), nil
	case *ort.Tensor[int32]:
		return int(t.GetData()[0]), nil
	}
	return 0, fmt.Errorf("expected int tensor, got %T", v)
}

type graphs struct {
	m            *asr.Manifest
	pre, enc, dj *graph
}

func openGraphs(dir string, m *asr.Manifest, ep string) (*graphs, error) {
	g := &graphs{m: m}
	var err error
	if g.pre, err = openGraph(dir, m.Preprocessor, ep); err != nil {
		return nil, err
	}
	if g.enc, err = openGraph(dir, m.Encoder, ep); err != nil {
		g.close()
		return nil, err
	}
	if g.dj, err = openGraph(dir, m.DecoderJoint, ep); err != nil {
		g.close()
		return nil, err
	}
	return g, nil
}

func (g *graphs) close() {
	for _, x := range []*graph{g.pre, g.enc, g.dj} {
		if x != nil {
			x.s.Destroy()
		}
	}
}

// preprocess returns log-mel features laid out [F, frames] and the valid frame count.
func (g *graphs) preprocess(pcm []float32) ([]float32, int, error) {
	w, err := floatTensor(ort.NewShape(1, int64(len(pcm))), pcm)
	if err != nil {
		return nil, 0, err
	}
	l, err := intTensor(g.pre.inDType(1), ort.NewShape(1), int64(len(pcm)))
	if err != nil {
		w.Destroy()
		return nil, 0, err
	}
	ins := []ort.Value{w, l}
	defer destroyAll(ins)
	outs, err := g.pre.run(ins)
	if err != nil {
		return nil, 0, err
	}
	defer destroyAll(outs)
	data, shape, err := floats(outs[0])
	if err != nil {
		return nil, 0, err
	}
	valid, err := firstInt(outs[1])
	if err != nil {
		return nil, 0, err
	}
	return trimFrames(data, int(shape[1]), int(shape[2]), valid), valid, nil
}

// encode runs the encoder on [F, frames] features; returns [D, outFrames].
func (g *graphs) encode(feats []float32, frames int) ([]float32, int, error) {
	f := g.m.NumFeatures
	x, err := floatTensor(ort.NewShape(1, int64(f), int64(frames)), feats)
	if err != nil {
		return nil, 0, err
	}
	l, err := intTensor(g.enc.inDType(1), ort.NewShape(1), int64(frames))
	if err != nil {
		x.Destroy()
		return nil, 0, err
	}
	ins := []ort.Value{x, l}
	defer destroyAll(ins)
	outs, err := g.enc.run(ins)
	if err != nil {
		return nil, 0, err
	}
	defer destroyAll(outs)
	data, shape, err := floats(outs[0])
	if err != nil {
		return nil, 0, err
	}
	if int(shape[1]) != g.m.EncoderDim {
		return nil, 0, fmt.Errorf("encoder output dim %d, manifest says %d", shape[1], g.m.EncoderDim)
	}
	valid, err := firstInt(outs[1])
	if err != nil {
		return nil, 0, err
	}
	return trimFrames(data, int(shape[1]), int(shape[2]), valid), valid, nil
}

// trimFrames keeps the first `valid` columns of a [rows, cols] row-major matrix.
func trimFrames(data []float32, rows, cols, valid int) []float32 {
	if valid >= cols {
		return data
	}
	out := make([]float32, rows*valid)
	for r := 0; r < rows; r++ {
		copy(out[r*valid:(r+1)*valid], data[r*cols:r*cols+valid])
	}
	return out
}

type lstmState struct{ h, c []float32 }

type ortJoint struct {
	g      *graphs
	enc    []float32 // [D, frames]
	frames int
}

func (g *graphs) joint(enc []float32, frames int) asr.Joint {
	return &ortJoint{g: g, enc: enc, frames: frames}
}

func (j *ortJoint) InitialState() asr.DecoderState {
	n := j.g.m.PredLayers * j.g.m.PredHidden
	return lstmState{h: make([]float32, n), c: make([]float32, n)}
}

func (j *ortJoint) Step(t, last int, st asr.DecoderState) ([]float32, []float32, asr.DecoderState, error) {
	m, dj := j.g.m, j.g.dj
	s := st.(lstmState)
	frame := make([]float32, m.EncoderDim)
	for d := range frame {
		frame[d] = j.enc[d*j.frames+t]
	}
	stateShape := ort.NewShape(int64(m.PredLayers), 1, int64(m.PredHidden))
	var ins []ort.Value
	defer func() { destroyAll(ins) }()
	add := func(v ort.Value, err error) error {
		if err != nil {
			return err
		}
		ins = append(ins, v)
		return nil
	}
	if err := add(floatTensor(ort.NewShape(1, int64(m.EncoderDim), 1), frame)); err != nil {
		return nil, nil, nil, err
	}
	if err := add(intTensor(dj.inDType(1), ort.NewShape(1, 1), int64(last))); err != nil {
		return nil, nil, nil, err
	}
	if err := add(intTensor(dj.inDType(2), ort.NewShape(1), 1)); err != nil {
		return nil, nil, nil, err
	}
	if err := add(floatTensor(stateShape, s.h)); err != nil {
		return nil, nil, nil, err
	}
	if err := add(floatTensor(stateShape, s.c)); err != nil {
		return nil, nil, nil, err
	}
	outs, err := dj.run(ins)
	if err != nil {
		return nil, nil, nil, err
	}
	defer destroyAll(outs)
	logits, _, err := floats(outs[0])
	if err != nil {
		return nil, nil, nil, err
	}
	h, _, err := floats(outs[2])
	if err != nil {
		return nil, nil, nil, err
	}
	c, _, err := floats(outs[3])
	if err != nil {
		return nil, nil, nil, err
	}
	nTok := m.BlankID + 1
	if len(logits) != nTok+len(m.Durations) {
		return nil, nil, nil, fmt.Errorf("joint logits %d, want %d", len(logits), nTok+len(m.Durations))
	}
	return logits[:nTok], logits[nTok:], lstmState{h: h, c: c}, nil
}
```

```go
package ortengine

import (
	"context"
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"sync"
	"time"

	"github.com/thegr8yg/ramblocal/internal/asr"
)

// MinSamples: clips shorter than 100 ms return an empty Result without running the model.
const MinSamples = asr.SampleRate / 10

const maxSymbolsPerFrame = 10 // must match tools/export greedy config

type Config struct {
	ModelDir string
	ORTLib   string
	EPs      []string // tried in order; default cuda, dml, cpu
}

type Engine struct {
	mu  sync.Mutex // one inference at a time; the scheduler (Phase 2) orders callers
	m   *asr.Manifest
	tok *asr.Tokenizer
	g   *graphs
	ep  string
}

// New opens the model on the first execution provider that loads and survives a warm-up run.
func New(cfg Config) (*Engine, error) {
	if err := InitRuntime(cfg.ORTLib); err != nil {
		return nil, fmt.Errorf("init onnxruntime: %w", err)
	}
	m, err := asr.LoadManifest(filepath.Join(cfg.ModelDir, "manifest.json"))
	if err != nil {
		return nil, err
	}
	f, err := os.Open(filepath.Join(cfg.ModelDir, "vocab.txt"))
	if err != nil {
		return nil, err
	}
	tok, err := asr.LoadVocab(f)
	f.Close()
	if err != nil {
		return nil, err
	}
	if tok.Size() != m.VocabSize {
		return nil, fmt.Errorf("vocab.txt has %d pieces, manifest vocab_size %d", tok.Size(), m.VocabSize)
	}
	eps := cfg.EPs
	if len(eps) == 0 {
		eps = []string{"cuda", "dml", "cpu"}
	}
	var errs []error
	for _, ep := range eps {
		g, err := openGraphs(cfg.ModelDir, m, ep)
		if err == nil {
			e := &Engine{m: m, tok: tok, g: g, ep: ep}
			if _, err = e.Transcribe(context.Background(), make([]float32, asr.SampleRate), asr.Options{}); err == nil {
				return e, nil
			}
			g.close()
		}
		errs = append(errs, fmt.Errorf("%s: %w", ep, err))
	}
	return nil, fmt.Errorf("no execution provider worked: %w", errors.Join(errs...))
}

func (e *Engine) Name() string { return "ort-" + e.ep }
func (e *Engine) EP() string   { return e.ep }

func (e *Engine) Close() error {
	e.mu.Lock()
	defer e.mu.Unlock()
	if e.g != nil {
		e.g.close()
		e.g = nil
	}
	return nil
}

func (e *Engine) Transcribe(ctx context.Context, pcm []float32, _ asr.Options) (asr.Result, error) {
	res := asr.Result{AudioSec: float64(len(pcm)) / asr.SampleRate}
	if err := ctx.Err(); err != nil {
		return res, err
	}
	if len(pcm) < MinSamples {
		return res, nil
	}
	e.mu.Lock()
	defer e.mu.Unlock()
	if e.g == nil {
		return res, errors.New("engine closed")
	}

	t0 := time.Now()
	feats, frames, err := e.g.preprocess(pcm)
	if err != nil {
		return res, err
	}
	t1 := time.Now()
	enc, outFrames, err := e.g.encode(feats, frames)
	if err != nil {
		return res, err
	}
	t2 := time.Now()
```

```go
// NormalizeEN lowercases, removes apostrophes, turns other punctuation into spaces, and collapses whitespace.
func NormalizeEN(s string) string {
	var b strings.Builder
	for _, r := range strings.ToLower(s) {
		switch {
		case unicode.IsLetter(r) || unicode.IsDigit(r):
			b.WriteRune(r)
		case r == '\'' || r == '’':
			// "don't" -> "dont"
		default:
			b.WriteRune(' ')
		}
	}
	return strings.Join(strings.Fields(b.String()), " ")
}
```

```go
// Package eval computes accuracy metrics.
package eval

import (
	"strings"

	"github.com/thegr8yg/ramblocal/internal/text"
)

type Corpus struct {
	Errors, RefWords, Utterances int
}

func (c *Corpus) Add(ref, hyp string) {
	r := strings.Fields(text.NormalizeEN(ref))
	h := strings.Fields(text.NormalizeEN(hyp))
	c.Errors += EditDistance(r, h)
	c.RefWords += len(r)
	c.Utterances++
}

// WER returns the corpus word error rate in percent.
func (c *Corpus) WER() float64 {
	if c.RefWords == 0 {
		return 0
	}
	return 100 * float64(c.Errors) / float64(c.RefWords)
}

// EditDistance is the word-level Levenshtein distance (substitutions + deletions + insertions).
func EditDistance(ref, hyp []string) int {
	prev := make([]int, len(hyp)+1)
	cur := make([]int, len(hyp)+1)
	for j := range prev {
		prev[j] = j
	}
	for i := 1; i <= len(ref); i++ {
		cur[0] = i
		for j := 1; j <= len(hyp); j++ {
			cost := 1
			if ref[i-1] == hyp[j-1] {
				cost = 0
			}
			cur[j] = min(prev[j]+1, cur[j-1]+1, prev[j-1]+cost)
		}
		prev, cur = cur, prev
	}
	return prev[len(hyp)]
}
```

```go
		out = append(out, v)
```

```go
package bench

import (
	"math"
	"sort"
)

// Pct holds latency percentiles in milliseconds.
type Pct struct {
	P50 float64 `json:"p50"`
	P95 float64 `json:"p95"`
	Max float64 `json:"max"`
}

// Percentiles uses the nearest-rank method.
func Percentiles(ms []float64) Pct {
	if len(ms) == 0 {
		return Pct{}
	}
	s := append([]float64(nil), ms...)
	sort.Float64s(s)
	rank := func(p float64) float64 {
		i := int(math.Ceil(p/100*float64(len(s)))) - 1
		return s[max(0, min(i, len(s)-1))]
	}
	return Pct{P50: rank(50), P95: rank(95), Max: s[len(s)-1]}
}
```

```go
package bench

import (
	"context"
	"encoding/json"
	"fmt"
	"io"
	"time"

	"github.com/thegr8yg/ramblocal/internal/asr"
	"github.com/thegr8yg/ramblocal/internal/eval"
)

type Report struct {
	Engine      string         `json:"engine"`
	GPU         string         `json:"gpu"`
	Date        string         `json:"date"`
	Items       int            `json:"items"`
	AudioSec    float64        `json:"audio_sec"`
	WallSec     float64        `json:"wall_sec"`
	RTF         float64        `json:"rtf"`
	WER         float64        `json:"wer"`
	Latency     map[string]Pct `json:"latency_ms"`
	VRAMMB      int            `json:"vram_mb"`
	ColdStartMS float64        `json:"cold_start_ms"`
}

func ms(d time.Duration) float64 { return float64(d.Microseconds()) / 1000 }

// Run transcribes every item (after `warmup` untimed runs of the first item) and writes one HypLine per item to hyps.
func Run(ctx context.Context, e asr.Engine, items []Item, load func(string) ([]float32, error), warmup int, hyps io.Writer) (Report, error) {
	r := Report{Engine: e.Name(), Date: time.Now().Format("2006-01-02"), Latency: map[string]Pct{}}
	if len(items) == 0 {
		return r, fmt.Errorf("no items")
	}
	if warmup > 0 {
		pcm, err := load(items[0].Audio)
		if err != nil {
			return r, err
		}
		for i := 0; i < warmup; i++ {
			if _, err := e.Transcribe(ctx, pcm, asr.Options{}); err != nil {
				return r, fmt.Errorf("warm-up: %w", err)
			}
		}
	}
	stages := map[string][]float64{}
	var corpus eval.Corpus
	enc := json.NewEncoder(hyps)
	var wall time.Duration
	for _, it := range items {
		pcm, err := load(it.Audio)
		if err != nil {
			return r, fmt.Errorf("%s: %w", it.Audio, err)
		}
		start := time.Now()
		res, err := e.Transcribe(ctx, pcm, asr.Options{})
		total := time.Since(start)
		if err != nil {
			return r, fmt.Errorf("%s: %w", it.Audio, err)
		}
		wall += total
		r.AudioSec += float64(len(pcm)) / asr.SampleRate
		corpus.Add(it.Text, res.Text)
		stages["total"] = append(stages["total"], ms(total))
		stages["mel"] = append(stages["mel"], ms(res.Timings.Mel))
		stages["encoder"] = append(stages["encoder"], ms(res.Timings.Encoder))
		stages["decoder"] = append(stages["decoder"], ms(res.Timings.Decoder))
		stages["detok"] = append(stages["detok"], ms(res.Timings.Detok))
		if err := enc.Encode(HypLine{Audio: it.Audio, Hyp: res.Text, Seconds: total.Seconds()}); err != nil {
			return r, err
		}
	}
	for k, v := range stages {
		r.Latency[k] = Percentiles(v)
	}
	r.Items = len(items)
	r.WallSec = wall.Seconds()
	r.WER = corpus.WER()
	if r.AudioSec > 0 {
		r.RTF = r.WallSec / r.AudioSec
	}
	return r, nil
}

// Score builds a report from hypotheses produced elsewhere (NeMo reference, Whisper baseline).
func Score(engine string, items []Item, hyps []HypLine) (Report, error) {
	r := Report{Engine: engine, Date: time.Now().Format("2006-01-02"), Latency: map[string]Pct{}}
	byAudio := make(map[string]HypLine, len(hyps))
	for _, h := range hyps {
		byAudio[h.Audio] = h
	}
	var corpus eval.Corpus
	var totals []float64
	for _, it := range items {
		h, ok := byAudio[it.Audio]
		if !ok {
			return r, fmt.Errorf("no hypothesis for %s", it.Audio)
		}
		corpus.Add(it.Text, h.Hyp)
		if h.Seconds > 0 {
			totals = append(totals, h.Seconds*1000)
			r.WallSec += h.Seconds
		}
	}
	r.Items = len(items)
	r.WER = corpus.WER()
	if len(totals) > 0 {
		r.Latency["total"] = Percentiles(totals)
	}
	return r, nil
}
```

```go
package bench

import (
	"errors"
	"fmt"
	"os"
	"time"
)

const staleLock = 2 * time.Hour

// AcquireGPULock serializes GPU benchmarks across processes using an exclusive lock file.
func AcquireGPULock(path string, timeout time.Duration) (func(), error) {
	deadline := time.Now().Add(timeout)
	for {
		f, err := os.OpenFile(path, os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o644)
		if err == nil {
			fmt.Fprintf(f, "%d\n", os.Getpid())
			f.Close()
			return func() { os.Remove(path) }, nil
		}
		if !errors.Is(err, os.ErrExist) {
			return nil, err
		}
		if st, serr := os.Stat(path); serr == nil && time.Since(st.ModTime()) > staleLock {
			os.Remove(path)
			continue
		}
		if time.Now().After(deadline) {
			return nil, fmt.Errorf("GPU lock %s held by another benchmark", path)
		}
		time.Sleep(100 * time.Millisecond)
	}
}
```

```go
		if err != nil {
			return nil, err
		}
		defer f.Close()
		pcm, rate, err := audio.ReadWAV(f)
		if err == nil && rate != 16000 {
			err = fmt.Errorf("%s: sample rate %d, want 16000 (run bench/prep-librispeech.ps1)", p, rate)
		}
		return pcm, err
	}
	r, err := bench.Run(context.Background(), e, items, load, *warmup, hf)
	must(err)
	gpu, after, _ := bench.QueryGPU()
	r.GPU, r.VRAMMB, r.ColdStartMS = gpu, after-before, float64(cold.Microseconds())/1000
	write(*out, r)
}

func cmdScore(args []string) {
	fs := flag.NewFlagSet("score", flag.ExitOnError)
	manifest := fs.String("manifest", "", "items JSONL")
	hyps := fs.String("hyps", "", "hypotheses JSONL")
	engine := fs.String("engine", "", "engine name for the report")
	out := fs.String("out", "", "report JSON path")
	fs.Parse(args)

	items := loadItems(*manifest, 0)
	f, err := os.Open(*hyps)
	must(err)
	defer f.Close()
	h, err := bench.LoadHyps(f)
	must(err)
	r, err := bench.Score(*engine, items, h)
	must(err)
	write(*out, r)
}

func loadItems(path string, limit int) []bench.Item {
	f, err := os.Open(path)
	must(err)
	defer f.Close()
	items, err := bench.LoadItems(f)
	must(err)
	if limit > 0 && limit < len(items) {
		items = items[:limit]
	}
	return items
}

func write(path string, r bench.Report) {
	b, _ := json.MarshalIndent(r, "", "  ")
	fmt.Println(string(b))
	if path != "" {
		must(os.MkdirAll(filepath.Dir(path), 0o755))
		must(os.WriteFile(path, b, 0o644))
	}
}

func must(err error) {
	if err != nil {
		fail(err)
	}
}

func fail(err error) {
	fmt.Fprintln(os.Stderr, "rbbench:", err)
	os.Exit(1)
}
```

`tools/baseline/nemo_reference.py` (runs on Lambda in the Task 0.4 venv; copy `bench/data/test-clean` there):
```python
"""Transcribe a manifest with NeMo (greedy, max_symbols=10) and write hyps JSONL."""
import argparse
import json
import pathlib

from omegaconf import open_dict
import nemo.collections.asr as nemo_asr


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--model", default="nvidia/parakeet-tdt-0.6b-v2")
    ap.add_argument("--manifest", required=True)
    ap.add_argument("--out", required=True)
    args = ap.parse_args()

    m = nemo_asr.models.ASRModel.from_pretrained(args.model).eval()
    dc = m.cfg.decoding
    with open_dict(dc):
        dc.strategy = "greedy"
        dc.greedy.max_symbols = 10
    m.change_decoding_strategy(dc)

    base = pathlib.Path(args.manifest).parent
    items = [json.loads(l) for l in open(args.manifest, encoding="utf-8") if l.strip()]
    paths = [str(base / it["audio"]) for it in items]
    hyps = m.transcribe(paths, batch_size=16)
    if isinstance(hyps, tuple):
        hyps = hyps[0]
    with open(args.out, "w", encoding="utf-8") as f:
        for it, h in zip(items, hyps):
            text = h.text if hasattr(h, "text") else h
            f.write(json.dumps({"audio": it["audio"], "hyp": text}) + "\n")


if __name__ == "__main__":
    main()
```

`tools/baseline/whisper_bench.py` (runs on the dev machine, same GPU, with the GPU lock released by rbbench first):
```python
"""Transcribe a manifest with faster-whisper and write hyps JSONL with per-item seconds."""
import argparse
import json
import pathlib
import time

from faster_whisper import WhisperModel


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--model", default="large-v3-turbo")
    ap.add_argument("--compute-type", default="int8")
    ap.add_argument("--manifest", required=True)
    ap.add_argument("--out", required=True)
    ap.add_argument("--limit", type=int, default=0)
    args = ap.parse_args()

    model = WhisperModel(args.model, device="cuda", compute_type=args.compute_type)
    base = pathlib.Path(args.manifest).parent
    items = [json.loads(l) for l in open(args.manifest, encoding="utf-8") if l.strip()]
    if args.limit:
        items = items[: args.limit]
    # Warm-up so the first item's time excludes model load and CUDA init.
    list(model.transcribe(str(base / items[0]["audio"]), language="en", beam_size=1)[0])
    with open(args.out, "w", encoding="utf-8") as f:
        for it in items:
            start = time.perf_counter()
            segments, _ = model.transcribe(str(base / it["audio"]), language="en", beam_size=1,
                                           vad_filter=False, condition_on_previous_text=False)
            text = " ".join(s.text.strip() for s in segments)
            secs = time.perf_counter() - start
            f.write(json.dumps({"audio": it["audio"], "hyp": text, "seconds": secs}) + "\n")


if __name__ == "__main__":
    main()
```
